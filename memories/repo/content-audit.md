## Audit Criteria (7-point check — from garden-roi-content skill)

Run each check on every file:

1. **Hook** — Does the opening sentence earn the read? (specific claim, problem, or action — not a setup, not "X is a great crop")
2. **Closer** — Is there a motivational summary paragraph? (if yes: cut or rewrite)
3. **Burstiness** — Read aloud. Does pace vary across sentences, or does it flow at uniform AI tempo?
4. **Vocabulary** — Any flagged words? (delve, tapestry, robust, leverage, unlock, underscore, pivotal, realm, harness, showcase, camaraderie; phrases: "play a significant role," "that being said," "at its core," "a key takeaway is")
5. **Citations** — Any "studies show" / "research indicates" / "experts agree" without author + year?
6. **Structure** — Over-bulleted? Uniform paragraph lengths throughout? Every H2 the same length?
7. **Positive saturation** — Does the piece acknowledge failure or difficulty anywhere, without immediately pivoting to reassurance?

**Scoring:** Flag any file that fails 2 or more checks. One isolated instance is a quick fix; 2+ means the piece needs a real pass.
